## Sobre o OnTrack

O **OnTrack** é uma plataforma desenvolvida para simplificar a análise e o acompanhamento do mercado financeiro brasileiro (B3). A aplicação une cotações de ativos em tempo real com um agente consultor baseado em inteligência artificial.

## Arquitetura do Sistema

A aplicação é dividida em dois componentes principais que se comunicam via API REST:

1. **Front-end Web:**
   - Desenvolvido com HTML5, CSS3 e JavaScript.
   - Interface interativa para envio de mensagens, solicitação de análises e renderização de gráficos.
2. **Back-end Python (Flask):**
   - **`app.py`:** Servidor HTTP responsável por expor as rotas da API (como a rota `/chat`), tratar requisições HTTP POST e gerenciar o CORS.
   - **`agente.py`:** Núcleo do agente de inteligência artificial que interage com a API do Gemini, busca históricos de ações via `yfinance` (adicionando a extensão `.SA` aos ativos da B3) e salva as imagens dos gráficos no diretório `static/graficos/`.

---

## Recursos e Dependências

- **Python & Flask:** Estrutura e rotas da aplicação web.
- **Google GenAI (Gemini API):** Processamento de linguagem natural do consultor.
- **economatica:** Leitura de histórico de preços, variações e cotações das ações brasileiras.
- **matplotlib:** Renderização e salvamento dos gráficos financeiros no servidor.

## Configuração do Ambiente Local

Para rodar a aplicação localmente no seu computador:

1. **Ative o seu ambiente virtual Python (`venv`):**
   ```bash
   python -m venv venv
   # No Linux/macOS:
   source venv/bin/activate
   # No Windows:
   .\venv\Scripts\activate
   ```
